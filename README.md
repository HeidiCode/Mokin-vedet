# Taavetin vedet

A self-contained interactive web page presenting the "Taavetin vedet" process.

## Live demo

https://heidicode.github.io/Taavetin-vedet/

## Structure

- `index.html` — the full standalone page (markup + inline JS)
- `style.css` — styles

No build step and no dependencies: open `index.html` in a browser to run it locally.

## Deployment

Hosted on GitHub Pages, served from the `main` branch. Any push to `main`
publishes automatically.
