Component

Progress bar

Shows how far through a process you are. It sticks to the top of the screen while the steps scroll beneath it, full width and on the page colour.

Anatomy

ClassRole
.progressSticky row at the top of a process, full bleed, ground-coloured, with a 2px ink rule below.
.progress__countAccent counter, done/total, fixed width.
.progress__track14px white track with a 2px ink border.
.progress__fillInk fill. Its width is set by script as a percentage.

Best practices

Do

  • Update it every time a step is marked done or rewound.
  • Keep the count and the bar in step: both come from the same number.

Don't

  • Show a percentage; steps are what people count.
  • Animate it when the user prefers reduced motion.

Accessibility

  • The track is a role="progressbar" with its value as text, "3/12 vaihetta valmiina". The visible count is aria-hidden so it is not read twice.
  • When a step is marked done, a hidden live region says so: "Vaihe 3 valmis. 3/12."
  • In Windows high-contrast mode the fill switches to the system text colour so the bar does not go empty.
