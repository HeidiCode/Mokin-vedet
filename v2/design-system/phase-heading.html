Component

Phase heading

A process is split into phases, such as the sauna cottage and the upper cottage. Each phase opens with an uppercase label and a 25px heading on a heavy rule, so a phase reads as a real division.

Best practices

Do

  • Number phases: Vaihe 1, Vaihe 2.
  • Name a phase by place, so people know where to walk.

Don't

  • Skip the label; it is the heading screen readers navigate by.
  • Nest phases inside phases.

Accessibility

  • The label is the <h2> under the page's <h1>.
  • Steps are numbered across the whole process, not per phase, so the number always matches the progress bar.
