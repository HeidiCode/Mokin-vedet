Introduction

Metsä

Metsä is the design system behind Mökin vedet v2, a small web app that walks the family through opening and closing a summer cottage's water system, one step at a time. It collects the colours, type, spacing and components the app is built from, and the reasons behind them.

What it is for

The app is used at the cottage: outdoors, on a phone, often with cold or busy hands, by people who do this twice a year and do not remember the steps. Every decision in Metsä serves that moment. The same system is meant for three readers:

Principles

Metsä grew out of user testing on the first version of the app. Each principle answers something testers ran into.

  1. Readable at arm's lengthBody text is 17px and headings 25px. Testers found the first version too small to read at the cottage.
  2. One thing at a timeOnly the current step is white, raised and open. Done and locked steps recede, so the eye lands where the work is.
  3. Calm, not alarmingNo red. A warning is a note to read, not an error, and state is shown with fill, badge and shape rather than colour alone.
  4. Show what can be tappedPhotos carry an AVAA bar, buttons have hard shadows and press in. Testers did not realise the photos opened.
  5. Say what happensButtons are written out in words. The completion modal says that closing it starts the guide again.

How to use it

Load the fonts and the two stylesheets, tokens first. Components are plain HTML with the class names shown on each component page.

<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&family=Space+Grotesk:wght@400..700&display=swap" rel="stylesheet">
      <link rel="stylesheet" href="themes/tokens.css">
      <link rel="stylesheet" href="themes/stylesV2.css">

To change a value, edit tokens.json and run python3 v2/design-system/build-tokens.py. Never edit tokens.css by hand, and never write a raw colour or size into a component: reach for a token.

The app's interface is in Finnish, so the examples on this site are too.
