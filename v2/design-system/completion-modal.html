Completion modal

When the last step is marked done, this modal says so. Closing it resets the process to the start, and it says that in words, because testers did not know.

Best practices

Do

  • Say what closing will do before the button.
  • Close with one clear button.

Don't

  • Close the modal on an outside tap; the reset should be a choice.
  • Add a second action.

Accessibility

  • It is a dialog labelled by its message.
  • It moves focus to the button when it opens and keeps Tab there.
  • Closing returns focus to the step list.
